# ssau-sto-report

Skill для Claude, который помогает писать и проверять учебные документы Самарского университета им. Королёва по стандарту **СТО 02068410-004-2018 «Общие требования к учебным текстовым документам»** (издание 2019 года с Изменением № 1).

Подходит для курсовых, ВКР и пояснительных записок, отчётов по практике и лабораторным, рефератов, РГР и других учебных текстовых документов.

## Что умеет

- **Оформляет** документы (.docx, LaTeX, Markdown) по стандарту: параметры страницы, порядок структурных элементов, нумерация разделов и перечислений, рисунки, таблицы, формулы, ссылки, требования к изложению текста.
- **Проверяет** готовый документ и указывает каждое нарушение с номером пункта стандарта (например, «п. 6.1.8: подпись должна быть под рисунком»).
- Содержит шаблоны титульного листа и задания на ВКР (бакалавриат, магистратура, специалитет) и примеры оформления списка источников по ГОСТ 7.1.

Отвечает на языке, на котором вы пишете. Цитаты из документа и термины стандарта всегда приводятся по-русски.

## Установка

**Claude Code**: склонируйте репозиторий в папку навыков:

```bash
git clone https://github.com/r3dfx080/claude-ssau-sto-report ~/.claude/skills/ssau-sto-report
```

**Claude.ai / Claude desktop**: заархивируйте папку в .zip и загрузите в «Настройки → Возможности → Навыки» (Settings → Capabilities → Skills).

Claude подключает навык сам, когда вы просите оформить или проверить курсовую, ВКР, отчёт, пройти нормоконтроль и т. п.

## Примеры запросов

- «Проверь мою курсовую `Term_paper_2025.docx` на соответствие СТО»
- «Сделай титульный лист ВКР для магистратуры, направление 09.04.01»
- «Оформи список литературы по ГОСТ 7.1»
- «Сгенерируй шаблон отчёта по лабораторной в .docx по нашему стандарту»
