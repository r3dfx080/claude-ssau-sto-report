# Title page and task forms (Appendices А, Б of the standard)

The title page uses the university/department form when one exists (п. 5.1.1); otherwise build it like the template below. All lines centred unless noted, no first-line indent, no page number. Templates are "recommended" (forms by the управление занятости и карьеры); a кафедра may issue its own — prefer theirs if the user has it.

## ВКР title page (Appendix А)

```
            МИНИСТЕРСТВО НАУКИ И ВЫСШЕГО ОБРАЗОВАНИЯ
                     РОССИЙСКОЙ ФЕДЕРАЦИИ

             ФЕДЕРАЛЬНОЕ ГОСУДАРСТВЕННОЕ АВТОНОМНОЕ
         ОБРАЗОВАТЕЛЬНОЕ УЧРЕЖДЕНИЕ ВЫСШЕГО ОБРАЗОВАНИЯ
  «САМАРСКИЙ НАЦИОНАЛЬНЫЙ ИССЛЕДОВАТЕЛЬСКИЙ УНИВЕРСИТЕТ
                ИМЕНИ АКАДЕМИКА С. П. КОРОЛЕВА»
                    (Самарский университет)

              Институт ______________________
              Факультет _____________________
              Кафедра _______________________

            ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА

                         «ТЕМА»

      по направлению подготовки 00.00.00 Наименование
                  (уровень бакалавриата)
          направленность (профиль) «Наименование»

Студент ____________________________________ И.О. Фамилия
Руководитель ВКР,
степень, звание ____________________________ И.О. Фамилия
Консультант (при наличии) __________________ И.О. Фамилия
Нормоконтролер (при наличии) _______________ И.О. Фамилия

                        Самара 20__
```

Variants by level:
- **Бакалавриат**: "по направлению подготовки …", "(уровень бакалавриата)".
- **Магистратура**: "по направлению подготовки …", "(уровень магистратуры)".
- **Специалитет**: "по специальности 00.00.00 Наименование", "(уровень специалитета)", then "специализация № 0 «Наименование»" (if set by ФГОС ВО), then направленность. Нормоконтролер is not optional here.

Signature block: labels left-aligned, signature line, initials-surname right-aligned. Topic in quotes and CAPS. "Самара" + year at the bottom.

For coursework / lab / practice reports, keep the same header (ministry, university, институт/факультет/кафедра) and replace the middle with the document type (e.g. "ПОЯСНИТЕЛЬНАЯ ЗАПИСКА К КУРСОВОМУ ПРОЕКТУ", "ОТЧЁТ ПО ЛАБОРАТОРНОЙ РАБОТЕ № 1"), the discipline, the topic, and a signature block (Выполнил: студент группы …, Проверил: должность, И.О. Фамилия). The standard gives no fixed template for these — follow the кафедра's form if the user has one.

## Задание на ВКР — first page (Appendix Б)

Usually a standard form (п. 5.2.1); self-made only with the supervisor's approval. Two recommended layouts:

**Form 1** — same university header with Институт/Факультет/Кафедра; right-aligned approval block:
```
                                         УТВЕРЖДАЮ
                                    Заведующий кафедрой
                              подпись ______ (инициалы, фамилия)
                              «___» ____________ 20__ г.

          ЗАДАНИЕ НА ВЫПУСКНУЮ КВАЛИФИКАЦИОННУЮ РАБОТУ
                (специалист, магистр, бакалавр)
студенту (ке) ____________ (фамилия, имя, отчество)
группа № ________
Тема работы ________
Цель работы (и/или исходные данные) ________
Структурные части работы (перечень вопросов, подлежащих разработке) ________

Научный руководитель                    Задание принял к исполнению
должность, кафедра
подпись ____ (инициалы, фамилия)        подпись ____ (инициалы, фамилия)
«___» ________ 20__ г.                  «___» ________ 20__ г.
```

**Form 2** — header + Кафедра only; same УТВЕРЖДАЮ block ("(подпись) / И.О.Фамилия"); then:
```
       Задание на выпускную квалификационную работу (ВКР)
Студенту(ке) ________ (ФИО, полностью)
группы ________
1. Тема ВКР: ________
   утверждена приказом по университету от «___» ______ 20__ г. № ___
2. Перечень вопросов, подлежащих разработке в ВКР: ________
3. Консультанты по разделам ВКР (при наличии):
   раздел ВКР: ____  разрабатываемые вопросы: ____
   должность, степень / подпись / И.О.Фамилия
4. Дата выдачи задания: «___» ______ 20__ г.
5. Срок представления на кафедру законченной ВКР: «___» ______ 20__ г.
Руководитель ВКР   должность, степень / подпись / И.О.Фамилия
Задание принял к исполнению   подпись студента / И.О.Фамилия студента
```
